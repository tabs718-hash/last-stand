# LAST DRAW 1.0 — измерения и границы проверки

Замеры CPU выполнены в одной среде Linux / Node 24.22.1. Это headless-измерения, не FPS браузера. Скрипт для воспроизведения: `npm run benchmark`. Нагрузка: 32 постоянных следа, 12 852 вершины проецированных повреждений. Цифры зависят от устройства, JIT, GC и нагрузки среды.

| Операция | 0.7, среднее | 1.0, среднее |
| --- | ---: | ---: |
| Обновление 32 следов | 7,175 мс | 1,177 мс |
| Создание нового следа | 44,710 мс | 10,236 мс |
| Обновление без следов | 0,019 мс | менее 0,001 мс |

p95 обновления 32 следов: 8,597 → 4,107 мс. p95 создания: 91,322 → 13,647 мс. Это не жёсткие гарантии задержки: сборщик мусора и браузерная отрисовка в эти значения не включены.

Изменения: постоянный кэш топологии, повторно используемые вершины/рабочие векторы, обновление только задействованных источников, ранний выход без следов. Пиксели атласов переиспользуются между перезапусками, а GPU-текстуры каждого экземпляра освобождаются независимо. На паузе и при скрытой модели повторная оценка неизменившейся позы пропускается. Сравнение с прямым вычислением skinning после поворота тела, смещения группы и вытеснения старых следов даёт максимальную ошибку около 6,1×10⁻⁸ м в тестовом сценарии.

Статичная улица сохранила 192 исходных элемента и 2 848 треугольников, объединённых в 11 мешей по материалам и теневым флагам. Это сокращает потенциальные вызовы рисования улицы с 192 до 11 в цветном проходе; реальное число зависит от отсечения камерой и теневых проходов. Геометрия/раскладка проверяются автоматически.

Начальный граф JavaScript отделён от Rapier/WASM. Проверка `scripts/verify-build.mjs` вычисляет фактические размеры, проверяет независимую загрузку физики, наличие файлов и SHA-256 четырёх GLB, затем создаёт `dist/release.json`. В 0.7 весь клиент находился в одном начальном JS-файле около 1,18 МБ gzip. В 1.0 начальный граф около 0,34 МБ gzip; оставшийся модуль физики загружается отдельно. Это помогает показать интерфейс/индикатор загрузки раньше, но не означает сокращение общего объёма или гарантированное ускорение первого доступного хода. Совместимый Rapier всё ещё содержит WASM в большом vendor-чанке; его предупреждение Vite не скрыто.

Физический шаг/подшаги, массы, ограничения мышц и правила дуэли в 1.0 не менялись. Время физики на этом стенде колебалось около 1,4–1,8 мс на общий такт; различие между запусками не приписывается оптимизации физики.

Браузерный preview relay недоступен в текущей среде. Нельзя считать проверенными здесь GPU FPS, pointer lock, звук и визуальную композицию WebGL на реальном устройстве. Для них приложен TESTING.md. Успешная публикация подтверждает размещение файлов, а не прохождение ручной приёмки.
