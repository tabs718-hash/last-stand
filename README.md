# LAST DRAW 1.2.0

## Запуск на компьютере

Установите Node.js 22 или новее с https://nodejs.org/ . Распакуйте проект и откройте терминал в папке с package.json:

```sh
npm ci
npm run dev
```

Откройте адрес из терминала, обычно http://localhost:5173 . Пока игра открыта, терминал должен работать; Ctrl+C останавливает сервер. Открытие index.html двойным щелчком не подходит: моделям и физике требуется HTTP-сервер.

Готовая папка docs не требует сборки. Если установлен Python:

```sh
python -m http.server 8000 --directory docs
```

Откройте http://localhost:8000 . На Windows вместо python иногда используется py.

## GitHub Pages

1. Создайте отдельный репозиторий для игры. На GitHub Free для Pages он должен быть публичным.
2. Распакуйте ZIP и загрузите СОДЕРЖИМОЕ папки в корень репозитория: package.json и docs должны находиться непосредственно в корне.
3. Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: /docs → Save.
4. Дождитесь публикации; адрес появится в Settings → Pages.

Папка docs содержит готовую production-сборку 1.2.0 с относительными адресами модулей и моделей. Она работает по адресу /имя-репозитория/. Загрузка только ZIP не подходит: Pages не распаковывает игру.

## Обновления

После изменения исходников выполните npm run build, замените содержимое docs файлами из dist и сохраните docs/.nojekyll. Загрузите изменения на GitHub.

npm test — автоматические проверки. Мышь — прицел, ПКМ — прицеливание, ЛКМ — достать/выстрелить, F — перезарядка, R — новая дуэль, P — пауза.

Ручная приёмка: TESTING.md. Архитектура/история: DEVELOPMENT.md. Происхождение ассетов: ASSET_LICENSES.md. Экспорт не содержит идентификаторов или конфигурации прежнего приватного размещения. Сторонние зависимости сохраняют собственные лицензии.
